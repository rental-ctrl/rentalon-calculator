# 렌탈ON V26 — 상담/고객DB 중심 GitHub Pages 버전

## 이번 V26의 핵심
기존의 "모든 제조사 가격·옵션·렌탈료 자동 계산" 구조를 버리고,
**차량 기본정보 → 고객 조건 입력 → 상담신청 → 고객DB → 상담상태 관리 → 견적/계약** 흐름으로 재설계했습니다.

### 고객 화면
- 차량 찾기
- 브랜드/차급/차량명 검색
- 예산으로 상담 신청
- 차량 선택 후 상담 신청
- 계약기간 / 주행거리 / 보증금 / 선납금 / 월예산 / 상담희망시간
- 본인인증은 현재 데모 버튼
- 상담 신청 데이터 저장

### 관리자 화면
- 신규 / 상담중 / 견적진행 / 계약완료 / 전체 DB 집계
- 고객명/차량/연락처 검색
- 상담 상태 변경
- CSV 내보내기

## 중요
현재 GitHub Pages는 정적 웹호스팅이므로 실제 여러 기기에서 공유되는 고객 DB, 관리자 로그인, 실제 휴대폰 본인인증은 포함되어 있지 않습니다.
상담 데이터는 테스트를 위해 브라우저 localStorage에 저장됩니다.
